# Signed Graph Active Learning

This project implements binary semi-supervised learning on signed graphs. Positive
and negative edge weights represent similarity and dissimilarity. Active learning
selects additional vertices to label based on synchronization frustration.

The available learners are:

- Laplace learning (`Laplace`)
- Poisson learning (`Poisson`)

The available graph variants are `signed`, `cut`, and `unsigned`.

## Setup

Python 3.10 or newer is recommended because the source uses modern type hints.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Prepared datasets are stored under `data/`. If a dataset directory is missing,
generate the prepared datasets with:

```bash
python data/datasets.py
```

Dataset generation may download source datasets and can take significant time.

## Command line usage

Run active learning directly with `main.py`:

```bash
python main.py \
    --dataset MNIST_0_1 \
    --classifier Poisson \
    --variant signed \
    --num-iter 75 \
    --num-trials 1
```

The same command can be run through the wrapper:

```bash
./run.sh --dataset MNIST_0_1 --classifier Poisson --variant signed
```

Use `python main.py --help` or `./run.sh --help` for the complete argument
list.

| Argument | Default | Description |
| --- | --- | --- |
| `--dataset` | required | Prepared dataset to load |
| `--classifier` | `Poisson` | `Poisson` or `Laplace` |
| `--variant` | `signed` | `signed`, `cut`, or `unsigned` |
| `--init-label-per-class` | `5` | Initially labeled vertices per class |
| `--label-per-iter` | `10` | New labels acquired per iteration |
| `--num-iter` | `75` | Active-learning iterations per trial |
| `--add-edges-per-node` | `3` | Maximum positive and negative edges added per new vertex; `0` disables additions |
| `--num-trials` | `1` | Independent trials to average |

Supported dataset names are:

```text
MNIST_0_1
MNIST_4_9
MNIST_EVEN_ODD
FASHIONMNIST_SANDAL_SNEAKER
CIFAR_CAT_DOG
CLUSTERS
```

`CLUSTERS` is generated by `data/datasets.py` and must exist under `data/`
before it can be selected.

Each run writes:

- `results/<DATASET>.json` — the per-iteration history, averaged when more than one trial is requested
- `figures/<DATASET>/error_rate.png` — the mislabeled-rate plot

## Python API

Load a prepared graph and run one trial:

```python
from data.datasets import load_dataset
from main import Graph

W, y = load_dataset("MNIST_0_1")
graph = Graph(W, y)

history = graph.RunActiveLearning(
    classifier="Poisson",
    variant="signed",
    init_label_per_class=5,
    label_per_iter=10,
    num_iter=75,
    add_edges_per_node=3,
    center_poisson_scores=True,
    seed=42,
)
```

Run and average independent trials with the same options:

```python
average = graph.average_histories(
    5,
    classifier="Poisson",
    variant="signed",
    label_per_iter=10,
    num_iter=75,
    add_edges_per_node=3,
    seed=42,
)
```

Each averaged trial runs on a fresh copy of the graph. When a seed is supplied,
successive trials use successive seed values.

## Plotting

`plot.py` provides both an axes-level plotting function and a convenience saver:

```python
import plot as learner_plot

learner_plot.save_plot(history, "figures/example/error_rate.png")
```

`history` is a list of records containing `iteration` and `mislabeled_rate`,
along with the active-learning metrics recorded by `RunActiveLearning()`.
